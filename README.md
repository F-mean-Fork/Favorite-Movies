The "Favorite-Movies" repository is a pet project built using Vue 3 and Vite. It primarily serves as a movie listing application, where users can search for and view details about their favorite movies. The project includes features such as:

Movie Search: Users can search for movies by title.
Detailed Movie Information: Displays key details about selected movies.
Responsive UI: Designed with a responsive interface for various devices.
The project leverages Vue 3's modern capabilities, including single-file components.
